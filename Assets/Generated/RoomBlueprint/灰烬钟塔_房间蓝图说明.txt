《灰烬钟塔》房间式地图蓝图说明
说明：该文档描述每个独立房间的功能、结构、点位和传送门连接。
最新结构调整：主塔攀登路线不再拆成独立房间，而是并入钟塔大厅，形成“钟塔大厅 + 主塔竖井”一体房。
流程重点：获得旧日赐福后，玩家从中央赐福石碑室传送回钟塔大厅，再从大厅内部直接完成主塔攀登。

[Room_01_开场落点]
功能：开场动画结束后玩家落入游戏的第一个房间。
结构：简单地面、左侧封闭边界、右侧传送门。
点位：Narrative_开场残响。
入口传送门：Portal_In_01 -> 上一房间/开场入口
出口传送门：Portal_Out_01 -> Room_02_荒凉小径_战斗教学
教学重点：认识起点和前进方向。
备注：作为玩家第一次进入游戏后的落点。

[Room_02_荒凉小径_战斗教学]
功能：移动、跳跃、攻击和小怪教学。
结构：主地面、两个小平台。
点位：2 到 3 个小怪、Narrative_攻击教学。
入口传送门：Portal_In_01 -> Room_01_开场落点
出口传送门：Portal_Out_01 -> Room_03_篝火休整区
教学重点：通过低平台和小怪建立基本操作。
备注：战斗获得灰烬的节奏可以从这里开始铺垫。

[Room_03_篝火休整区]
 功能：篝火/存档点教学。
结构：安全主地面、少量空旷空间。
点位：SavePoint_篝火、Narrative_篝火提示。
入口传送门：Portal_In_01 -> Room_02_荒凉小径_战斗教学
出口传送门：Portal_Out_01 -> Room_04_断桥教学区
教学重点：让玩家看到安全空间和存档点。
备注：用于节奏缓冲。

[Room_04_断桥教学区]
功能：第一次遇到无法通过的断桥。
结构：左侧地面、右侧地面、中间断裂缺口。
点位：Gate_需要灰烬态、Interact_断桥石碑。
入口传送门：Portal_In_01 -> Room_03_篝火休整区
出口传送门：Portal_Out_01 -> Room_05_灰烬态通桥区
教学重点：提示玩家普通状态无法通过，需要灰烬态显现旧桥。
备注：出口用能力门逻辑表达“暂时无法通行”。

[Room_05_灰烬态通桥区]
功能：第一次通过灰烬态桥梁。
结构：主地面、灰烬态平台桥。
点位：Narrative_按R切相。
入口传送门：Portal_In_01 -> Room_04_断桥教学区
出口传送门：Portal_Out_01 -> Room_06_钟塔前庭_投剑战斗区
教学重点：按 R 切相后通过灰烬平台。
备注：这里验证灰烬态地形显现机制。

[Room_06_钟塔前庭_投剑战斗区]
功能：进入钟塔前的战斗区。
结构：主地面、几个高台。
点位：普通敌人、精英敌人。
入口传送门：Portal_In_01 -> Room_05_灰烬态通桥区
出口传送门：Portal_Out_01 -> Room_07_投掷宝剑教学区
教学重点：在进入钟塔大厅前安排一次小型战斗。
备注：投掷宝剑能力房间不是孤立奖励房，而是从前庭战斗自然过渡过去。

[Room_07_投掷宝剑教学区]
功能：获得投掷宝剑并立即教学。
结构：普通地面、平台、远程机关、出口门。
点位：Ability_投掷宝剑、Mechanism_远程机关、Gate_投剑开启出口、少量敌人。
入口传送门：Portal_In_01 -> Room_06_钟塔前庭_投剑战斗区
出口传送门：Portal_Out_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
教学重点：玩家先经过一段普通挑战，再获得投掷宝剑，然后必须用投掷宝剑命中远程机关打开出口。
备注：能力点位于房间中后段。

[Room_08_钟塔大厅_Hub_主塔攀登一体房]
功能：主枢纽房间，同时包含完整主塔竖向攀登路线。
结构：底部大厅、分支传送门、篝火、旧日赐福能力门、纵向主塔竖井、普通平台、灰烬态平台、登顶机关、顶部出口。
点位：SavePoint_大厅篝火、Narrative_大厅说明、Gate_需要旧日赐福_开启主塔攀登、Mechanism_主塔火冰复合机关、多个敌人点。
入口传送门：Portal_In_01 -> 上一房间/各分支返回
出口传送门：
Portal_Out_To_Room_10_齿轮廊道 -> Room_10_齿轮廊道_冲刺前段
Portal_Out_To_Room_13_熔灰工坊 -> Room_13_熔灰工坊_火魔法前段
Portal_Out_To_Room_16_静霜钟室 -> Room_16_静霜钟室_冰魔法前段
Portal_Out_To_Room_25_Boss前休整室 -> Room_25_Boss前休整室
教学重点：未获得旧日赐福前，玩家只能看到/尝试大厅上方的主塔路线；获得旧日赐福后，从大厅内部直接完成完整攀登。
备注：主塔攀登路线不再拆成单独房间，它就是钟塔大厅向上的竖向延伸。

[Room_10_齿轮廊道_冲刺前段]
功能：进入冲刺区域前的普通挑战。
结构：普通平台、齿轮机关预告、敌人点。
点位：Mechanism_齿轮机关预告、普通敌人。
入口传送门：Portal_In_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
出口传送门：Portal_Out_01 -> Room_11_齿轮廊道_冲刺获取区
教学重点：用普通平台和敌人预告冲刺区域的机关节奏。
备注：这是冲刺能力线的前置房间。

[Room_11_齿轮廊道_冲刺获取区]
功能：获得冲刺。
结构：普通平台、机关、能力点、宽裂隙、出口门。
点位：Ability_冲刺、Mechanism_宽裂隙、Gate_冲刺通过出口。
入口传送门：Portal_In_01 -> Room_10_齿轮廊道_冲刺前段
出口传送门：Portal_Out_01 -> Room_12_齿轮廊道_冲刺教学区
教学重点：先经过普通机关平台，再获得冲刺，后半段必须用冲刺跨过宽裂隙。
备注：能力点嵌入正常房间路线中。

[Room_12_齿轮廊道_冲刺教学区]
功能：连续使用冲刺的教学房间。
结构：宽裂隙、小平台、危险区域。
点位：Hazard_冲刺危险区、少量敌人。
入口传送门：Portal_In_01 -> Room_11_齿轮廊道_冲刺获取区
出口传送门：Portal_Out_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
教学重点：让玩家连续使用冲刺完成移动挑战。
备注：完成后回到大厅。

[Room_13_熔灰工坊_火魔法前段]
功能：火魔法区域前段。
结构：熔炉地形、平台、火炬机关预告。
点位：Mechanism_火炬预告、敌人点。
入口传送门：Portal_In_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
出口传送门：Portal_Out_01 -> Room_14_熔灰工坊_火魔法获取区
教学重点：预告火魔法将用于点燃机关。
备注：作为火魔法能力线的入口挑战。

[Room_14_熔灰工坊_火魔法获取区]
功能：获得火之魔法。
结构：普通平台、能力点、火炬机关、出口门。
点位：Ability_火之魔法、Mechanism_火炬机关、Gate_火魔法开启出口。
入口传送门：Portal_In_01 -> Room_13_熔灰工坊_火魔法前段
出口传送门：Portal_Out_01 -> Room_15_熔灰工坊_火魔法教学区
教学重点：获得火魔法后立刻点燃机关打开出口。
备注：能力点在房间中后段。

[Room_15_熔灰工坊_火魔法教学区]
功能：使用火之魔法解决机关。
结构：多个火炬机关、平台、敌人。
点位：Mechanism_连续火炬_01、Mechanism_连续火炬_02、敌人点。
入口传送门：Portal_In_01 -> Room_14_熔灰工坊_火魔法获取区
出口传送门：Portal_Out_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
教学重点：连续使用火魔法处理机关。
备注：完成后回到大厅。

[Room_16_静霜钟室_冰魔法前段]
功能：冰魔法区域前段。
结构：平台、水面/冻结区预告、敌人。
点位：Mechanism_水面预告、敌人点。
入口传送门：Portal_In_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
出口传送门：Portal_Out_01 -> Room_17_静霜钟室_冰魔法获取区
教学重点：预告冰魔法将用于冻结或暂停机关。
备注：作为冰魔法能力线的入口挑战。

[Room_17_静霜钟室_冰魔法获取区]
功能：获得冰之魔法。
结构：普通平台、能力点、冻结水面/暂停机关、出口门。
点位：Ability_冰之魔法、Mechanism_冻结水面、Gate_冰魔法通过出口。
入口传送门：Portal_In_01 -> Room_16_静霜钟室_冰魔法前段
出口传送门：Portal_Out_01 -> Room_18_静霜钟室_冰魔法教学区
教学重点：获得冰魔法后立刻冻结水面或暂停机关通过。
备注：能力点在房间中后段。

[Room_18_静霜钟室_冰魔法教学区]
功能：使用冰之魔法解决房间挑战。
结构：冻结机关、高台、平台、出口门。
点位：Mechanism_暂停机关、Gate_冰机关出口。
入口传送门：Portal_In_01 -> Room_17_静霜钟室_冰魔法获取区
出口传送门：Portal_Out_01 -> Room_19_古老纪念堂入口
教学重点：使用冰魔法处理更完整的机关挑战。
备注：完成冰魔法线后进入纪念堂路线。

[Room_19_古老纪念堂入口]
功能：进入纪念堂前的过渡房间。
结构：安静空间、少量平台。
点位：Narrative_纪念堂入口。
入口传送门：Portal_In_01 -> Room_18_静霜钟室_冰魔法教学区
出口传送门：Portal_Out_01 -> Room_20_旧日长廊
教学重点：降低节奏，提示纪念堂区域。
备注：从能力挑战转入叙事区域。

[Room_20_旧日长廊]
功能：摆放好友石碑、头像和寄语的主长廊。
结构：长廊地面、一排或两排石碑、少量平台。
点位：Interact_旧日石碑_01 到 Interact_旧日石碑_10。
入口传送门：Portal_In_01 -> Room_19_古老纪念堂入口
出口传送门：Portal_Out_01 -> Room_21_中央赐福石碑室
教学重点：通过多个可交互石碑表现旧日记忆。
备注：这里偏叙事和纪念功能。

[Room_21_中央赐福石碑室]
功能：获得旧日赐福。
结构：中央大型石碑、能力点、出口门。
点位：Interact_中央赐福石碑、Ability_旧日赐福、Gate_回大厅开启主塔攀登。
入口传送门：Portal_In_01 -> Room_20_旧日长廊
出口传送门：Portal_Out_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
教学重点：获得“灰烬态不再消耗灰烬值”后，返回大厅开启完整主塔攀登。
备注：这里不直接进入独立登顶房间，而是回到大厅竖井。

[Room_25_Boss前休整室]
功能：Boss 前准备房间。
结构：安全地面、篝火、少量文本。
点位：SavePoint_Boss前篝火、Narrative_Boss前提示。
入口传送门：Portal_In_01 -> Room_08_钟塔大厅_Hub_主塔攀登一体房
出口传送门：Portal_Out_01 -> Room_26_塔顶钟室_Boss
教学重点：Boss 前最后一次休整。
备注：玩家完成大厅竖井攀登后到达这里。

[Room_26_塔顶钟室_Boss]
功能：最终 Boss 战。
结构：主战斗平台、两侧高台、少量灰烬态平台。
点位：Boss_塔顶守护者。
入口传送门：Portal_In_01 -> Room_25_Boss前休整室
出口传送门：Portal_Out_01 -> Room_27_结局CG触发室
教学重点：综合检验移动、战斗、灰烬态和能力使用。
备注：Boss 后进入结局。

[Room_27_结局CG触发室]
功能：Boss 战后进入结局 CG。
结构：简单地面、结局触发点。
点位：Trigger_结局CG。
入口传送门：Portal_In_01 -> Room_26_塔顶钟室_Boss
出口传送门：无
教学重点：结束流程。
备注：流程结束。
